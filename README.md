# Italiano

Własna apka (PWA) do nauki włoskiego od zera. Plan i program kursu: [docs/PLAN.md](docs/PLAN.md).

```bash
npm install
npm run dev     # lokalnie
npm test        # testy silnika (sprawdzanie odpowiedzi, powtórki)
npm run build   # wersja produkcyjna do dist/
```

Push na `main` wdraża apkę na GitHub Pages. Treść lekcji jest w `src/content/`.
